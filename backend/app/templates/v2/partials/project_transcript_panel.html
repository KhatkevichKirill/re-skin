{# Localisation transcript panel (docs/localisation.md §7 / §8). Self-polls every 3s ONLY while a transcription is queued or running; every other state is terminal, so the rendered fragment drops the hx-* attributes and polling stops naturally (same pattern as partials/project_merges_list.html and run_status_content.html). Two rules the layout follows from that: 1. Nothing typeable is rendered in a polling state. The panel replaces its own innerHTML every 3s, so an input shown next to that spinner would lose a keystroke every three seconds. The editor therefore renders in the four NON-polling states (never requested / ready / empty / failed, plus a "pending" that analysis failure has stranded) — which is also what §8's fallback needs: a failed transcription has to leave the project usable by letting the operator type the lines in by hand. 2. Every state offers a way out. A transcription that is queued or running can be restarted (RQ kills a job at TRANSCRIBE_JOB_TIMEOUT and nothing writes "failed" for it, so "running" can outlive its worker), and every terminal state can be re-run or hand-edited. Rendered for localisation projects only — every other type has nothing to transcribe, and web_v2._transcript_context resolves the flag through spec_for() so an unknown project_type never turns this on. #} {% if is_localisation %}
